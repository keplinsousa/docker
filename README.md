# Meu Repositório de Containers 🚀

Este repositório contém meus arquivos Dockerfiles e Docker Compose, organizados para facilitar a criação e gerenciamento de containers.  

## Estrutura do Repositório 📂
- **dockerfiles/** → Diretório com arquivos Dockerfile organizados por imagens.
- **dockercompose/** → Diretório contendo arquivos Docker Compose, também organizados por imagens.

Cada pasta dentro desses diretórios representa uma imagem específica que eu criei. O objetivo deste repositório é armazenar e compartilhar configurações de containers de forma organizada.
